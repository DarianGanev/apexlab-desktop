# ApexLab Desktop v0.1.0 Foundation Implementation Plan

> **Execution rule:** Develop every production behavior test-first. Observe the focused test fail for the expected reason, add the smallest implementation, rerun it green, run the relevant suite, inspect the diff, and commit a coherent working state. Generated repository/project scaffolding is a setup exception, but it must restore and build before commit.

**Goal:** Create a private, reproducible GitFlow repository and release a tested, navigable, self-contained Windows desktop foundation for ApexLab.

**Architecture:** WPF is the composition root. UI-independent application contracts and the racing domain remain pure. UDP transport, the F1 25 protocol adapter, and persistence are separate projects. Version 0.1.0 proves repository hygiene, lifecycle ownership, configuration, navigation, diagnostics, CI, and packaging; it contains no fake telemetry behavior.

**Technology:** C# 14; WPF; .NET SDK 10.0.302/.NET 10 LTS; Generic Host; MSTest; Microsoft.Data.Sqlite; GitHub Actions on Windows; self-contained `win-x64` publishing.

**Source design:** `docs/superpowers/specs/2026-07-19-apexlab-desktop-design.md`
