# v0.3 Deterministic Canonical Replay Cache Implementation Plan

> Execute every behavior change test-first. Keep private evidence and generated cache files outside
> Git. Do not weaken an invariant merely to make the retained capture pass.

**Goal:** Build an integrity-checked local canonical replay cache whose checksum is deterministic for
identical F1 25 evidence and frozen version IDs, whose stale entries rebuild, and whose gaps and
filtered packets remain explicit.

**Architecture:** Infrastructure-neutral canonical packet contracts live in
`ApexLab.Telemetry.Abstractions`; F1 projection lives in `ApexLab.Protocols.F125`; ordered replay and
cache ports live in `ApexLab.Application`; raw input and binary cache persistence live in
`ApexLab.Persistence`; `ApexLab.Replay` only composes the production workflow for a closed private
gate.

**Design:**
[`2026-08-09-v0.3-deterministic-canonical-replay-design.md`](../specs/2026-08-09-v0.3-deterministic-canonical-replay-design.md)

**Frozen IDs:** `ea-f1-25-v3`, `apexlab-bahrain-tt-slice-v1`,
`f125-v3-minimal-decoder-v1`, `apexlab-canonical-sample-v1`
