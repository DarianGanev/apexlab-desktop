# Manually audited comparable Bahrain laps implementation plan

> **Execution rule:** implement in order with test-first red/green cycles. Keep private telemetry and
> generated audit documents outside Git. Run the full exact-head gate before publication.

**Goal:** Produce a deterministic, locally audited Bahrain lap inventory that becomes baseline-ready
only with five complete, contradiction-free, context-matched, manually included laps.

**Architecture:** Pure audit/baseline invariants live in Domain. Application assembles provisional lap
candidates from verified canonical records and validates complete audits. Persistence owns the strict
local JSON document and handle-safe publication. Replay supplies prepare/validate composition roots
and emits only a closed aggregate report.

**Tech stack:** C# 14, .NET 10, MSTest 4, strict `System.Text.Json`, existing canonical replay/cache,
Windows handle-safe local storage, PowerShell verification, GitHub Actions.

**Design:** `docs/superpowers/specs/2026-08-09-v0.3-manually-audited-comparable-laps-design.md`
