# v0.3 Bahrain Slice Contract Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Freeze Issue #24 as human-readable and machine-readable protocol, privacy, version, and
traceability contracts with executable invariants.

**Architecture:** Keep the contract independent from unfinished production code. A canonical JSON
document owns the selected F1 25 wire metadata and downstream traceability; a closed JSON Schema
owns commit-safe result shape; integration tests parse both artifacts directly and reject structural,
bounds, traceability, or privacy drift.

**Tech Stack:** Markdown, JSON, JSON Schema 2020-12, .NET 10, `System.Text.Json`, MSTest.

## Global Constraints

- Support only base F1 25 v3 through adapter `ea-f1-25-v3`.
- Freeze only offline Sakhir (Bahrain) Time Trial: track 3, game mode 5, session type 18, ruleset 2.
- Decode only the selected player-slot fields from Motion, Session, Lap Data, Event, and Car Telemetry.
- Real telemetry, source identities, hashes, paths, rates, timings, coordinates, and D1 audit values remain local.
- Vendor attachments stay ignored under `vendor-specs/`; no bytes or copied tables enter Git.
- No new NuGet dependency is permitted.

### Task 2: Add the normative machine-readable artifacts

**Files:**

- Create: `contracts/v0.3/bahrain-slice-v1.json`
- Create: `contracts/v0.3/bahrain-safe-summary-v1.schema.json`
- Test: `tests/ApexLab.IntegrationTests/Contracts/BahrainSliceContractTests.cs`

**Interfaces:**

- Produces: contract ID `apexlab-bahrain-tt-slice-v1` and schema ID
  `bahrain-safe-summary-v1`; later issues may cross-check but runtime code does not load them.

- [ ] **Step 1: Create the canonical slice contract**

  Use these top-level properties in order:

  ```json
  {
    "schemaVersion": 1,
    "contractId": "apexlab-bahrain-tt-slice-v1",
    "status": "frozen",
    "protocolSource": {},
    "supportedContext": {},
    "versionIds": {},
    "header": {},
    "packets": [],
    "manualAuditInputs": [],
    "downstreamTraceability": [],
    "safeSummarySchema": "contracts/v0.3/bahrain-safe-summary-v1.schema.json",
    "privacy": {}
  }
  ```

  Record the two official attachment names, byte lengths, and uppercase SHA-256 values from the
  design. Store fields using absolute offsets for Header/Session/Event and `{arrayBaseOffset,
  arrayCount, stride, memberOffset}` for player arrays. Every field records `wireName`, `width`,
  `wireType`, `unit`, and integer `consumers`.

- [ ] **Step 2: Populate only the selected wire fields**

  Freeze all 29 header bytes. Select Session context fields documented in the design; Motion world
  X/Y/Z; Lap last/current time, lap/total distance, lap number, pit/sector/invalid/driver/result
  states; Event code plus FLBK frame/time; and Telemetry speed/throttle/brake/gear. Do not add
  steering, RPM, setup, tyre, damage, or generalized event fields.

- [ ] **Step 3: Create the closed safe-summary schema**

  Set `$schema` to `https://json-schema.org/draft/2020-12/schema`, use
  `additionalProperties: false`, and require exactly these properties:

  ```text
  schemaVersion, schemaId, status, validationDate, gameBuild, applicationVersion,
  adapterId, contractId, decoderId, canonicalSchemaId, lapAuditId, alignmentId,
  referenceId, cornerRevisionId, detectorId, experimentProtocolId,
  baselineMinimumMet, findingDisposition, experimentOutcome, deterministicReplay,
  provenanceComplete, privateDataExcluded, conclusion
  ```

  Use constants for every version identity, a SemVer pattern for `applicationVersion`, a strict
  date pattern, a bounded path-free game-build pattern, categorical finding/outcome enums, and
  `allOf` conditions so `status=passed` requires all gates true, a finding, a non-`not_run` outcome,
  and `conclusion=PASS`; abstention requires `not_run` and `FAIL`.

- [ ] **Step 4: Run the focused tests and verify GREEN**

  Run the Task 1 command. Expected: all `BahrainSliceContractTests` pass with no warnings.

  ```powershell

  git commit -m "test: freeze Bahrain slice contract"
  ```
