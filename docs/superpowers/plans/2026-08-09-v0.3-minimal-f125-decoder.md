# v0.3 Minimal F1 25 Decoder Implementation Plan

> **Execution note:** Follow this plan test-first in the isolated
> `codex/v0.3-minimal-decoder` worktree. Do not add canonical-cache, audit, UI, or coaching behavior.

**Goal:** Decode the five frozen Bahrain slice packet families into typed unit-bearing values,
fail closed on malformed selected input, and prove the decoder against both independent synthetic
fixtures and the owner's retained private base-v3 capture.

**Architecture:** Add allocation-free typed family decode results in `ApexLab.Protocols.F125`,
reuse the existing packet inspector for common compatibility ordering, and add checked absolute
little-endian field reads. Add a private replay-tool command that consumes finalized local evidence
and emits only a closed aggregate conclusion.

**Tech stack:** C# 14 / .NET 10, MSTest 4, existing raw-evidence replay components, PowerShell 5.1
verification scripts, GitHub Actions.

**Frozen design:**
[`2026-08-09-v0.3-minimal-f125-decoder-design.md`](../specs/2026-08-09-v0.3-minimal-f125-decoder-design.md)

**Issue:** [#25](https://github.com/DarianGanev/apexlab-desktop/issues/25)

## Constraints

- `contracts/v0.3/bahrain-slice-v1.json` is the field/offset/unit oracle.
- Production code must not load repository JSON at runtime.
- Fixtures use literal independently authored bytes and no private telemetry.
- Every selected floating value must be finite; ratios and documented bounded values fail closed.
- No packet result may retain a payload, span, sender, path, source ID, or source hash.
- Private output contains no counts, rates, IDs, field values, times, coordinates, or notes.
- Use `apply_patch` for edits, explicit-path staging, and the repository `Verify.ps1` gate.
