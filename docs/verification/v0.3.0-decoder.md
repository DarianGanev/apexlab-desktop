## Event limitation

The retained driving window did not contain a selected lifecycle Event. This is expected because
`SSTA`, `SEND`, and `FLBK` are asynchronous rather than continuously emitted. Their decoder offsets,
union fields, ignored-code behavior, malformed input handling, and finite-value checks are verified
independently by synthetic exact-layout fixtures. The private gate requires every continuously
emitted selected family and rejects any malformed selected packet it observes; it reports Event
presence without inventing one.

sender information, session or frame identity, packet volume, timing or rate, decoded driving value,
coordinate, setup value, or free-text private note. This verifies decoder compatibility only. It
does not establish lap comparability, canonical replay determinism, coaching correctness, or support
outside the frozen Bahrain Time Trial slice.
