## Private procedure

1. Use the packaged Windows build on the target PC.
2. In F1 25, select base F1 25 telemetry mode (not Season Pack), enable UDP, and use port `20777` with loopback delivery.
3. In ApexLab, arm a bounded capture and drive a short offline Time Trial.
4. Stop capture cleanly and confirm the UI reports finalized, integrity-verified evidence with no privacy-excluded records.
5. Privately verify the manifest digest. Do not copy the digest into this repository.
6. Replay the private capture twice with the same replay options.
7. Privately compare ordered classification/counter output and confirm both runs are identical, including recorded sequence gaps.
8. Compare ID/version/length/rate/frame aggregates with the earlier probe assumptions.
9. Run `scripts/CaptureSoak.ps1` at a synthetic sustained rate of at least 2x the privately measured peak. Do not claim the multiplier until this measurement exists.
10. Delete or retain private evidence according to the user's local policy; never commit it.
