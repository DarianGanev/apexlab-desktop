## Deferred distribution observations

- Clean Windows account without a development SDK: **not claimed for v0.1.0**. The runtime-isolated
  package test above proves the application starts without a PATH-visible SDK, while the roadmap
  reserves definitive clean-machine self-contained validation for the pre-v1.0 release gate.
- Microsoft Defender SmartScreen: **not claimed for v0.1.0**. The package is unsigned and may trigger
  a reputation warning. A representative browser-origin Mark-of-the-Web observation remains part of
  the pre-v1.0 Windows distribution gate because locally produced files do not carry that provenance.

These limitations remain explicit and are not converted into automated-success claims.

## Known limitations

- The package is unsigned and may trigger Windows reputation or SmartScreen warnings.
- Distribution is a portable self-contained ZIP, not an installer or auto-updater.
- The UI is the tested desktop shell; F1 25 UDP capture, replay, lap analysis, and coaching arrive in
  later milestones.
- Domain, protocol, and telemetry test assemblies are placeholders until those product slices begin.
- No public source-code license is granted by this package.
